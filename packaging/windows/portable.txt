FreeANDIY Photo portable mode

While this file sits next to freeandiy-photo.exe, FreeANDIY Photo keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the FreeANDIYPhotoData folder beside it, and writes
nothing to %APPDATA%. Copy the whole folder to move FreeANDIY Photo with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\Photocraft) instead.
If FreeANDIYPhotoData can't be written (for example on a read-only drive), FreeANDIY Photo says so and
uses %APPDATA%\Photocraft instead.
