# FreeANDIY Photo app icon

The angel Andy (Free Andy Agency) on the FreeANDIY Photo colour, with the `Ph` monogram. At 32 px
and below the angel is unreadable, so those sizes show the lowercase monogram `ph` instead.

These files are **generated**: do not edit them here. The source is
`freeandiy/tools/make_icons.py` (colours in `freeandiy/branding.toml`), and
`freeandiy/scripts/regenerate.sh` copies the output from `freeandiy/assets/icons/photo/`.

| File | Use |
|---|---|
| `freeandiy-photo.svg`, `freeandiy-photo-small.svg` | vector master (trace) |
| `freeandiy-photo-1024.png` | macOS window/Dock icon, on Apple's 824/1024 grid |
| `freeandiy-photo.icns` | macOS bundle icon |
| `freeandiy-photo.ico` | Windows icon, 16–256 px, embedded in the `.exe` |
| `hicolor/<size>/apps/agency.freeandy.photo.png`, `hicolor/scalable/...svg` | Linux icon theme, title bar mark |
